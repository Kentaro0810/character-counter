# 文字数カウンター

文章を入力すると、次の情報をリアルタイムで表示する静的Webアプリです。

- 文字数
- 空白を除いた文字数
- 行数
- 段落数
- 400字詰め原稿用紙の換算枚数
- 1分500文字として計算した読了時間

## 使用技術

- HTML
- CSS
- JavaScript
- GitHub Pages

## 特徴

- 入力内容は保存しません
- サーバーへの送信はありません
- PC、タブレット、スマートフォンに対応
- 分析結果をクリップボードへコピー可能

## 公開方法

1. GitHubで `character-counter` というPublicリポジトリを作成します。
2. `index.html`、`style.css`、`script.js`、`README.md`をアップロードします。
3. Settings → Pagesを開きます。
4. Sourceを「Deploy from a branch」にします。
5. Branchを `main`、フォルダーを `/(root)` にしてSaveします。
